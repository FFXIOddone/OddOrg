# OddOrg 1.11.0

OddOrg is an Ashita inventory organizer with per-character automatic care,
item rules, and a preview-first manual organization workflow.

## Highlights

- Automatic incoming-item sorting, free-Inventory targets from 1 to 80 slots,
  and optional nearby Ephemeral Moogle crystal/cluster deposits.
- Customizable OddOrg Default storage placement, per-item destinations,
  carried-item targets, Ignore rules, and temporary manual-retrieval holds.
- View Plan before Run organization. Runs confirm transfers and replan until
  no moves remain, or stop with a clear failure or bounded-convergence reason.
- Consolidation of compatible partial storage stacks and confirmed destination
  Auto Sort after storage transfers.
- Compact, resizable textured UI with contextual tooltips and state-driven
  actions. No mascot integration.
- Saved settings apply to the next plan/run without restarting the addon.
- Equipped gear is rechecked before ordinary transfer dispatch, including gear
  equipped after planning. Direct moves also enforce this check.

## Safety and limits

OddOrg does not sell or discard items. It respects item protections, loaded-bag
state, accessible storage, quantity limits, and confirmation of movement.
Automatic features are independently enabled per character. Failed or uncertain
movement stops rather than being blindly retried. A settings change stops an
active queue and invalidates the old preview.

The documented advanced `equipped` organization option intentionally permits
equipped gear; ordinary UI runs do not enable it. Explicit item protections
still apply. Full-bag checks are conservative, and organization stops on a
repeated bag state or at 16 passes. Moogle confirmation observes item removal;
the player should verify the stored balance.

## Install or upgrade

Extract `OddOrg-v1.11.0.zip` into the Ashita `addons` directory so the entrypoint
is `addons/oddorg/oddorg.lua`. Preserve `config/addons/oddorg` when upgrading.
Run `/addon load oddorg` or `/addon reload oddorg`, then `/oddorg`.
Use Settings to configure automatic care and item rules; use Bulk Run > View
Plan to review a manual organization before running it.
